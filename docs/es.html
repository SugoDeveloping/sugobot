Quick Start

Primeros pasos en tu servidor

Antes de empezar

  • El bot ya debe estar invitado al servidor.
  • La persona que lo configure deberia tener permisos de administrador o equivalentes.
  • Los modulos avanzados funcionan mejor si el bot puede gestionar canales, roles, mensajes, webhooks y archivos.
  • Las alertas de Twitch solo funcionan si el servicio del bot tiene ese acceso habilitado.

Orden recomendado

  1. Empieza con /setup.
  2. Revisa logs, bienvenida, idioma y branding.
  3. Desbloquea premium con /activate si corresponde.
  4. Configura solo los modulos que realmente necesita tu comunidad.

Lo mas comodo es empezar por lo basico y luego anadir tickets, verify, whitelist, reaction roles, giveaway o Twitch.

How It Works

Como se usa dentro del servidor

Estilo principal de uso

  • La mayoria de funciones empiezan con slash commands.
  • Muchos flujos siguen con botones, menus o modales.
  • Las acciones importantes suelen devolver confirmaciones privadas para no ensuciar canales publicos.

Personalizacion por servidor

  • Cada servidor puede tener idioma, nombre visible, icono y color propios.
  • Los mensajes del bot pueden verse alineados con la identidad de la comunidad.
  • Idiomas soportados: italiano, ingles y espanol.

Tipos de interaccion

Slash commands Botones Menus Modales Mensajes privados Publicaciones automaticas

Licensing

Free vs Premium

Siempre disponible

  • Configuracion general del bot.
  • Sistema de bienvenida.
  • Moderacion basica.
  • Comandos utilitarios como /help, /ping, /userinfo y /serverinfo.

Modulos premium

Tickets Newsletter Soporte Reaction Roles Verify Server Builder Utility Avanzada Twitch Whitelist Giveaway

Como se activa

  1. El owner del servicio entrega una clave valida.
  2. Un admin del servidor ejecuta /activate.
  3. Los modulos desbloqueados pasan a estar disponibles en ese servidor.
  4. Los comandos premium pueden usarse normalmente.

Moderation

Moderacion e historial del staff

Acciones directas

Ban, kick, timeout, unban y unmute se gestionan con slash commands y controles de seguridad.

Warnings

Los warnings se mantienen separados del historial general para que el staff los revise mas rapido.

Canales

Historial

/modlog y /warnings ayudan a ver lo que ya paso con un usuario.

Premium Module

Sistema de tickets

Funciones principales

  • Multiples categorias de ticket con sus propios botones.
  • Roles de staff y categorias Discord especificas por categoria.
  • Claim, anadir usuarios, renombrar y cerrar tickets.
  • Transcripts HTML automaticos en el canal configurado.
  • Transcript opcional por DM para quien abrio el ticket.
  • Recordatorios automaticos para tickets abiertos.

Comandos principales

  • /ticket-config
  • /ticket-category
  • /ticketmsg
  • /ticket-add
  • /ticket-rinomina
  • /ticket-stats

Premium Module

Solicitudes de soporte estructuradas

Este modulo no abre un canal privado por usuario. En su lugar crea una solicitud para el staff con acciones de claim, cierre y feedback. Tambien soporta prioridad, cooldown, limite de solicitudes abiertas y recordatorios.

Premium Module

Newsletter y listas de audiencia

/newsletter puede enviar mensajes a un rol, a una lista guardada o a un canal. Soporta embeds, titulo, imagen, thumbnail, footer y URL. /scanuser es un comando reservado al owner del bot para construir listas reutilizables.

Access

Reaction roles y verificacion

Reaction roles

  • Anade roles a mensajes existentes o crea paneles nuevos.
  • Puede usar botones o reacciones emoji.
  • Modos disponibles: toggle, add-only y unique.

Verify

  • Captcha visual con hasta 3 intentos.
  • Tiempo limite, refresco y kick opcional si falla.
  • Asigna automaticamente el rol verificado al completar el proceso.

Growth

Twitch y giveaways

Alertas Twitch

Monitoriza varios streamers por servidor, con canal de destino, rol ping y mensaje personalizado.

Chequeos automaticos

El bot revisa periodicamente los streamers seguidos y publica el aviso cuando estan en directo.

Giveaway

Crea sorteos con premio, duracion, rol requerido, numero de ganadores e imagenes.

Join / Leave

Los usuarios pueden entrar o salir con botones y el bot anuncia ganadores automaticamente.

Applications & Structure

Whitelist, builder y herramientas de estructura

Whitelist

  • Panel de solicitud con hasta 5 preguntas configurables.
  • Aprobar o rechazar desde botones staff.
  • DM opcionales y rol aprobado automatico.

Server Builder

  • Crea canales y categorias desde presets o desde un formato rapido de texto.
  • Soporta tags como private, readonly, nsfw, show, hide, slowmode y limit.
  • Muy util para montar o rehacer la estructura de una comunidad.

Herramientas avanzadas

  • /serverbackup: guarda y restaura plantillas reutilizables del servidor.
  • /nuke: comando destructivo solo para el owner con confirmacion explicita.

Operations

Herramientas de admin y owner

/activate

Lo usa un admin para activar modulos premium con una clave valida.

/gestione

Gestion premium solo para el owner: claves, estado y modulos activos.

/botadmin

Control del owner para bloquear o desbloquear servidores.

Herramientas ocultas

Algunos comandos existen solo para mantenimiento y no forman parte del uso normal del servidor.

Automation

Funciones automaticas

  • Recordatorios para tickets y solicitudes abiertas.
  • Chequeos automaticos de Twitch.
  • Cierre de giveaways y anuncio de ganadores.
  • Rotacion del estado del bot.
  • Mensajes de bienvenida para nuevos miembros.
