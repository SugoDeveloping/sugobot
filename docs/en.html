Quick Start

First steps in your server

Before you begin

  • The bot must already be invited to your Discord server.
  • The person configuring it should have administrator access or equivalent permissions.
  • Advanced modules work best when the bot can manage channels, roles, messages, webhooks and attachments.
  • Twitch alerts only work if the bot service has Twitch access configured.

Recommended order

  1. Run /setup first.
  2. Check logs, welcome message, language and branding.
  3. Unlock premium features with /activate if needed.
  4. Configure only the modules your community will actually use.

The easiest path is to start small, then add tickets, verification, whitelist, reaction roles, giveaways or Twitch later.

How It Works

What using the bot feels like

Main interaction style

  • Most features start with slash commands.
  • Many flows continue with buttons, select menus or modals.
  • Important actions usually reply with private confirmations instead of noisy public messages.

Per-server customization

  • Each server can have its own language, bot name, icon and embed color.
  • Messages can feel branded to the specific community.
  • Supported bot languages are Italian, English and Spanish.

Interaction types

Slash commands Buttons Select menus Modals DM messages Automatic posts

Free vs Premium

Always available

  • General bot setup.
  • Welcome system.
  • Core moderation commands.
  • Base utility commands like /help, /ping, /userinfo and /serverinfo.

Premium modules

Tickets Newsletter Support Reaction Roles Verify Server Builder Advanced Utility Twitch Whitelist Giveaway

Activation flow

  1. The bot owner provides a valid premium key.
  2. A server admin runs /activate.
  3. The unlocked module becomes available in that server.
  4. Premium commands that were blocked can now be used normally.

Moderation

Moderation and staff history

Direct actions

Ban, kick, timeout, unban and unmute all work through slash commands with safety checks.

Warnings

Warns stay separate from the full moderation log so staff can review both quickly.

Channel control

/purge cleans messages in bulk and /slowmode updates the current channel cooldown.

History

/modlog and /warnings help staff track what already happened to a member.

Premium Module

Ticket system

Main features

  • Multiple ticket categories with their own buttons.
  • Category-specific staff roles, Discord categories and opening messages.
  • Claim, add-user, rename and close actions.
  • Automatic HTML transcripts sent to the configured log channel.
  • Optional DM transcript for the ticket opener.
  • Automatic reminders for open tickets.

Main commands

  • /ticket-config
  • /ticket-category
  • /ticketmsg
  • /ticket-add
  • /ticket-rinomina
  • /ticket-stats

Premium Module

Structured support requests

This module is different from tickets. Instead of opening a private channel, it creates a staff-facing request item with claim, close and feedback actions. It supports priority, cooldowns, open request limits and reminders.

Premium Module

Newsletter and audience lists

/newsletter can send updates either to a role, to a scanned list, or to a channel. Messages support rich embeds, titles, thumbnails, images, footer text and clickable URLs. /scanuser is reserved for the bot owner and is used to build reusable recipient lists.

Access

Reaction roles and verification

Reaction roles

  • Add roles to an existing message or create a fresh panel.
  • Use buttons or emoji reactions.
  • Modes: toggle, add-only, unique.

Verify system

  • Image captcha verification with up to 3 attempts.
  • Timeout limit, refresh action and optional kick on failure.
  • Assigns the verified role automatically on success.

Growth

Twitch alerts and giveaways

Twitch alerts

Monitor multiple streamers per server, pick a target channel, optional ping role and custom alert message.

Automatic checks

The bot regularly checks followed streamers and posts a live alert when they go online.

Giveaways

Create giveaways with prize, duration, required role, winner count, images and reroll support.

Join / Leave

Users can join or leave giveaways through buttons, and winners are announced automatically when the giveaway ends.

Applications & Structure

Whitelist, builder and server structure tools

Whitelist

  • Custom application panel with up to 5 questions.
  • Approve or reject from staff buttons.
  • Optional DM notifications and automatic approved role assignment.

Server Builder

  • Create channels and categories from presets or a quick text format.
  • Supports tags like private, readonly, nsfw, show, hide, slowmode and voice limits.
  • Useful for fast setup or rebuilding a structured community server.

Advanced structure tools

  • /serverbackup: save and restore reusable server templates.
  • /nuke: destructive owner-only cleanup command with explicit confirmation.

Operations

Admin and owner tools

/activate

Used by server admins to enable premium modules with a valid key.

/gestione

Owner-only premium management: keys, status, enabling and disabling modules.

/botadmin

Owner-only control to block or unblock servers from using the bot.

Hidden maintenance tools

Some commands exist only for the bot owner and are not part of normal server usage.

Automation

Automatic features

  • Reminder messages for open tickets and support requests.
  • Automatic Twitch live checks.
  • Giveaway ending and winner announcement.
  • Rotating bot status messages.
  • Welcome messages for new members.
