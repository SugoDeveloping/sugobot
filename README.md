# SugoBot

Bot Discord modulare basato su `discord.js` e `better-sqlite3`, con moderazione, ticket, assistenza, newsletter, reaction roles, verifica, Twitch alerts, whitelist e automazioni per community.

## Sito GitHub Pages

La documentazione statica del progetto viene pubblicata automaticamente con GitHub Pages tramite GitHub Actions.

URL previsto del sito:

`https://sugodeveloping.github.io/sugobot/`

## Repository

Contenuto principale incluso:

- `src/` codice del bot
- `docs/` sito statico della documentazione multilingua
- `.github/workflows/deploy-pages.yml` deploy automatico di GitHub Pages
- `.env.example` esempio di configurazione ambiente

## Avvio locale

```bash
npm install
npm run docs
```

Il comando `npm run docs` serve la documentazione in locale dalla cartella `docs`.
